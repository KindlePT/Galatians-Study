# Greetings from Galatians: Study Companion
Static pages for our small group. No build step.
- `index.html` home page
- `night-1.html` Night 1 recap
- `paul-journey.html` interactive map
Publish: Settings > Pages > Deploy from branch > main / (root).
To add a night, copy `night-1.html`, edit the `MK`, `PE`, `WD`, `LT` arrays, and link it from `index.html`.
